## 🚀 Overview
In today’s digital era, users prefer quick and personalized recommendations directly on their messaging platforms[cite: 3]. This project is an automated movie recommendation system that interacts with users in real-time via WhatsApp[cite: 3]. 

By integrating WhatsApp automation, an AI Agent, and the Google Gemini Chat Model, the system understands natural user queries, fetches relevant movie data from a database, and delivers personalized suggestions 24/7[cite: 3]. It serves as a highly practical application of AI bridging entertainment and communication[cite: 3].

## ✨ Key Features
*   **Real-Time Interaction:** Instant, automated interactions directly through WhatsApp, eliminating the need for manual responses[cite: 3].
*   **Natural Language Processing:** Powered by AI for deep natural language understanding to interpret what users actually want to watch[cite: 3].
*   **Contextual Memory:** Equipped with short-term conversational memory to remember recent user inputs and preferences for a better chat experience[cite: 3].
*   **Dynamic Data Retrieval:** Seamlessly fetches movie titles, genres, release years, and ratings from a live Google Sheet database[cite: 3].
*   **Highly Scalable:** New movies can be added to the Google Sheet easily without altering the core code[cite: 3].

## 🛠️ System Architecture & Tech Stack
The system is built using a modern, multi-component architecture to ensure efficiency[cite: 3]:

*   **WhatsApp Trigger:** Captures incoming messages from the user and passes them to the AI agent[cite: 3].
*   **AI Agent (Core):** The central processing unit that handles user input, manages memory context, and fetches data from the database[cite: 3].
*   **Google Gemini Chat Model:** The "AI Brain" of the system, responsible for interpreting complex requests and generating natural, human-like replies[cite: 3].
*   **Simple Memory:** A module that provides short-term context to keep the conversation flowing naturally[cite: 3].
*   **Movies List (Google Sheets):** Acts as the external, easily updatable database for all movie metadata[cite: 3].
*   **Send Message:** The delivery module that pushes the AI-generated recommendations back to the user's WhatsApp chat[cite: 3].

## 🔄 How It Works (The Workflow)
1.  **User Query:** A user sends a movie-related query through WhatsApp (e.g., *"Suggest a comedy movie"*)[cite: 3].
2.  **Capture:** The WhatsApp Trigger catches the message and forwards it to the AI Agent[cite: 3].
3.  **Interpretation:** The AI Agent uses the Google Gemini Chat Model to interpret the intent of the message[cite: 3].
4.  **Data Fetching:** The AI Agent accesses the Movies List (Google Sheet) to find matching titles[cite: 3].
5.  **Generation:** The AI composes a personalized, conversational recommendation[cite: 3].
6.  **Delivery:** The response is sent back to the user on WhatsApp instantly[cite: 3].
